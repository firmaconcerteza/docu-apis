Autenticación

Todos los endpoints requieren un token de autenticación enviado en el header Authorization.

Token de acceso

cashin_*****

HTTP Header
Authorization: cashin_******

URL Base

Base URL https://ext.firmaconcerteza.com

Búsqueda de entidades

Busca personas naturales o jurídicas en la base de datos mediante texto libre, con modo normal o fuzzy.

POST /cashin/busqueda/1

Parámetros del body

CampoTipoReq.DescripciónValores
querystringSíTexto a buscarCualquier texto
tipostringSíTipo de entidadnatural / juridico
tipoBusquedastringSíModo de búsquedanormal / fuzzy
pagenumberSíPágina (desde 1)Entero positivo
sizenumberSíResultados por página10, 20, 50, 100

Ejemplos

bash
curl -X POST "https://ext.firmaconcerteza.com/cashin/busqueda/1" \
  -H "Content-Type: application/json" \
  -H "Authorization: cashin_*****" \
  -d '{
    "query": "jorge raul",
    "tipoBusqueda": "normal",
    "tipo": "natural",
    "page": 1,
    "size": 20
  }'
javascript
const response = await fetch('https://ext.firmaconcerteza.com/cashin/busqueda/1', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'cashin_****'
  },
  body: JSON.stringify({
    query: 'jorge raul',
    tipoBusqueda: 'normal',
    tipo: 'natural',
    page: 1,
    size: 20
  })
});

const data = await response.json();
console.log(data);

Detalle de entidad

Obtiene información completa de una entidad específica a partir de su UUID.

⚡ Respuesta dinámica: Los campos y secciones dentro de atributos varían según la entidad consultada. Cada entidad puede tener distintos títulos, secciones, subsecciones y campos dependiendo de la información disponible en las fuentes. El campo tipo de cada campo puede ser valor (dato simple) o tabla (JSON serializado como string que debe parsearse).

POST /cashin/entidad/1

Parámetros del body

CampoTipoReq.Descripción
idstringSíUUID de la entidad — formato xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Estructura de la respuesta

CampoTipoDescripción
exitobooleanResultado de la operación
datos._idstringUUID de la entidad
datos.nombre_entidadstringNombre completo normalizado
datos.tipo_entidadstringnatural o juridico
datos.atributosarrayGrupos de información — contenido dinámico
datos.atributos[].titulostringNombre del grupo, ej. General (17), Relaciones (4), PEP y Sancionados (4)
datos.atributos[].secciones[].campos[].tipostringvalor — dato simple · tabla — JSON serializado como string, debe parsearse con JSON.parse(campo.valor)
paginacionobjectPaginación cuando aplica
seguridadarrayNivel de acceso y restricciones
metadataarrayFuente y timestamp de generación

Ejemplos

bash
curl -X POST "https://ext.firmaconcerteza.com/cashin/entidad/1" \
  -H "Content-Type: application/json" \
  -H "Authorization: cashin_****" \
  -d '{"id": "14584ece-d734-531f-942a-1ab927563669"}'
javascript
const response = await fetch('https://ext.firmaconcerteza.com/cashin/entidad/1', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'cashin_****'
  },
  body: JSON.stringify({ id: '14584ece-d734-531f-942a-1ab927563669' })
});
const data = await response.json();

// Los atributos son dinámicos — iterar siempre
data.datos.atributos.forEach(grupo => {
  console.log(grupo.titulo); // "General (17)", "Relaciones (4)", etc.
  grupo.secciones.forEach(sec => {
    sec.subsecciones.forEach(sub => {
      sub.campos.forEach(campo => {
        if (campo.tipo === 'tabla') {
          const filas = JSON.parse(campo.valor); // array de objetos
          console.log(campo.campo, filas);
        } else {
          console.log(campo.display, campo.valor); // dato simple
        }
      });
    });
  });
});

400
Parámetros faltantes o inválidos
401
Token no proporcionado
403
Token inválido
500
Error interno del servidor

{
  "exito": false,
  "mensaje": "El campo 'id' es requerido en el body",
  "error": "Parámetro faltante"
}
json — 403 token inválido
{
  "exito": false,
  "mensaje": "Token inválido",
  "error": "El token proporcionado no es válido para cashin"
}

Notas importantes

Búsqueda normal vs fuzzy: normal hace coincidencia exacta o parcial. fuzzy tolera errores tipográficos.

Paginación: comienza en page: 1. Valores recomendados de size: 10, 20, 50, 100.

Formato de ID: los IDs son UUIDs con formato xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
